# فروشگاه اینترنتی پوشاک — پروژه فول‌استک

[English](./README.md) | **فارسی**

یک فروشگاه اینترنتی پوشاک شامل پنل مشتری و پنل ادمین. بک‌اند با **NestJS و MySQL** و فرانت‌اند با **React + Vite + Tailwind** ساخته شده است. رابط کاربری فارسی (راست‌به‌چپ) است.

## امکانات

**پنل مشتری**
- ثبت‌نام و ورود با شماره موبایل (توکن JWT به‌همراه refresh token)
- مرور محصولات بر اساس درخت دسته‌بندی (پوشاک مردانه / زنانه ← لباس، کیف، کفش، اکسسوری، ورزشی)، جستجو و فیلتر
- صفحه محصول همراه با محصولات مشابه و «اغلب باهم خریداری‌شده»
- سبد خرید، تسویه‌حساب با کد تخفیف، تاریخچه و جزئیات سفارش‌ها
- مدیریت چند آدرس، نشانه‌گذاری محصولات، کیف پول (شارژ، برداشت، تراکنش‌ها)
- تیکت پشتیبانی با مکالمه چندمرحله‌ای
- پیشنهاد شخصی‌سازی‌شده («برای شما») و پرفروش‌ترین‌ها
- درخواست بازیابی حساب برای کاربران غیرفعال‌شده

**پنل ادمین (`/admin`)**
- داشبورد
- مدیریت کامل (CRUD) محصولات و دسته‌بندی‌ها (با آپلود عکس) و کاربران
- مدیریت کدهای تخفیف
- بررسی سفارش‌ها: تایید، لغو، استرداد
- مشاهده کیف پول و تراکنش‌های هر کاربر
- مدیریت تیکت‌های پشتیبانی
- مدیریت درخواست‌های بازیابی حساب

**امکانات بک‌اند**
- مستندات Swagger در آدرس `/api`
- موتور پیشنهاد محصول (سیگنال‌های خرید، نشانه‌گذاری و بازدید با کاهش زمانی) به‌همراه اسکریپت‌های ارزیابی
- ردیابی IP و مسدودسازی موقت
- Seed دیتابیس با داده‌های فیک واقع‌گرایانه (کاربر، دسته‌بندی، محصول، سفارش، کیف پول)
- تست‌های واحد (Jest) و تنظیمات تست e2e

> درگاه پرداخت **شبیه‌سازی‌شده** است (`payment-provider.service.ts`) و همیشه پرداخت را موفق اعلام می‌کند. برای پرداخت واقعی طراحی نشده است.

## راه‌اندازی

### پیش‌نیازها
- Node.js نسخه ۲۰ یا بالاتر
- MySQL نسخه ۸ (یا سازگار) در حال اجرا روی سیستم

### ۱. ساخت دیتابیس
```sql
CREATE DATABASE store_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```
هر اسمی می‌توانید بگذارید، فقط باید با `DB_DATABASE` در فایل `.env` یکی باشد. جدول‌ها در اولین اجرا به‌صورت خودکار ساخته می‌شوند (`synchronize` در TypeORM).

### ۲. بک‌اند
```bash
cd ecommerce
npm install
cp .env.example .env     # اطلاعات دیتابیس و کلیدهای JWT را در آن وارد کنید
npm run seed             # اختیاری: پر کردن دیتابیس با داده‌ی نمونه
npm run start:dev
```
API روی `http://localhost:3000` و مستندات Swagger روی `http://localhost:3000/api` در دسترس است.

> ⚠️ دستور `npm run seed` قبل از درج داده‌ی نمونه، جدول‌های کاتالوگ، سفارش، سبد خرید، نشانه‌گذاری و کیف پول را **پاک می‌کند**. آن را روی دیتابیسی که برایتان مهم است اجرا نکنید.

### ۳. فرانت‌اند
```bash
cd shop-frontend
npm install
cp .env.example .env     # مقدار پیش‌فرض VITE_API_URL برابر http://localhost:3000 است
npm run dev
```
سپس `http://localhost:5173` را باز کنید.

## حساب‌های نمونه (ساخته‌شده با `npm run seed`)

| نقش | موبایل | رمز عبور |
|---|---|---|
| ادمین | `09123456789` | `1234` |
| ادمین | `09111111111` | `Test123!` |
| کاربر عادی | `09987654321` | `User123!` |
| کاربر عادی | `09222222222` | `Test123!` |

با حساب ادمین وارد شوید تا لینک پنل ادمین در منوی کاربری نمایش داده شود، یا مستقیماً به `/admin` بروید.

## اسکریپت‌های مفید (بک‌اند)

| دستور | توضیح |
|---|---|
| `npm run start:dev` | اجرا در حالت توسعه (watch) |
| `npm run build` / `npm run start:prod` | بیلد و اجرای نسخه production |
| `npm run seed` | ریست و seed داده‌ی نمونه |
| `npm run test` / `npm run test:cov` | تست واحد / پوشش تست |
| `npm run test:e2e` | تست‌های end-to-end |
| `npm run verify:recommender` | تست، بررسی و ارزیابی آفلاین سیستم پیشنهاد |
| `npm run lint` | ESLint (همراه با رفع خودکار) |

## عکس محصولات

عکس‌هایی که از پنل ادمین آپلود می‌شوند در `ecommerce/uploads/products` و `ecommerce/uploads/categories` ذخیره شده و توسط بک‌اند روی `/uploads/...` سرو می‌شوند. چند عکس نمونه هم در همین پوشه‌ها داخل مخزن قرار دارد.
